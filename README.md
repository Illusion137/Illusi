# Illusi
A mobile music application made in React-Native derived from YouTube and developed predominately for IOS, however it wouldn't be terribly difficult to port this to Android

This application would have to be side-loaded onto your IOS device as it would violate the IOS appstore's TOS to publish onto the IOS appstore 

Any requested features please email me @ raygoza.d@hotmail.com
